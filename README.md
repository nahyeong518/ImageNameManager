## ✨ 주요 기능
- 📂 **폴더 분류 및 이미지 파일 관리**: 트리 구조 폴더로 이미지와 문서를 직관적으로 분류
- ⚡ **화면 캡쳐(Win + Shift + S) 즉시 적용 & 다운로드 가능**: 작업표시줄 트레이 아이콘 원클릭 또는 자동 저장
- 📝 **메모장 통합 관리 기능 추가**: 기존 컴퓨터의 원본 파일은 안전하게 보존하며 프로그램 내에서 직접 작성 및 편집
- 🎨 **(더블클릭) 미리보기 창에서 이미지 & 메모장 디지털 뷰어 및 펜 필기**: 자유로운 손글씨 메모, 밑줄, 6색 컬러 팔레트 및 새 이미지로 저장
